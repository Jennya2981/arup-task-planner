# Проектный бриф — 8 лендингов услуг

Коротко: что делаем, для кого и в каких рамках. Подробности — в `README.md`
(как пользоваться) и `CONTEXT.md` (как устроено).

## Задача

Сделать восемь отдельных посадочных страниц услуг консалтинговой компании
для вставки в Tilda. Каждая страница — самостоятельная: свой текст, своя цена,
свой цветовой акцент. Общей сводной страницы нет и не будет.

## Что входит

- 8 страниц в двух видах: `preview/` (полные, для просмотра) и `tilda/`
  (сниппеты для блока **T123**).
- Единая дизайн-система: палитра из `Brand_style.jpg`, один шрифт Roboto,
  адаптив 360 / 768 / 1440.
- 20 подготовленных фотографий в `assets/img/` для загрузки в Tilda.
- Сборщик на Python (`src/`), без библиотек и фронтенд-сборки.

## Требования

1. **Страницы.** 8 отдельных страниц. Без шапки, футера и логотипа — они
   уже есть на сайте. Вставка — один блок T123 на страницу.
2. **Кнопки.** Ведут в попап Tilda по `#popup:ID`. Пока реальный ID не
   указан — стоит placeholder `zayavka`, и кнопка плавно скроллит к финалу.
3. **Шрифт.** Один Roboto на всех страницах, буквы и цифры, без исключений.
   Только начертания 300 / 400 / 500 (Bold не используется).
4. **Фото.** Натуральные, не тонируются: только `saturate(0.92)
   contrast(1.03) brightness(1.02)`. Подписи-кредиты на страницах нет
   (лицензия Pexels не требует указания авторства).
5. **Различия.** Страницы не должны выглядеть одинаково: у каждой свои
   цвета кнопок, полосы цифр, подложек и бонус-блока.
6. **Финальный блок.** Справа — фото, разное на всех 8, из фрагментов,
   не занятых на самой странице.
7. **Тексты.** Из исходных .docx не переписываются; допустимы авторский
   FAQ и микрокопирайт.
8. **Качество.** Адаптив 360/768/1440 без горизонтальной прокрутки,
   контраст текста не ниже WCAG AA, без библиотек и сборки.
