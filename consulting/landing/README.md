# Восемь лендингов услуг — «Тихая экспертиза»

Готовые страницы для сайта консалтинговой компании: кремовая бумага, глубокий
зелёный и шалфей, волосяные охристые акценты, один шрифт Roboto и натуральные
фотографии на тёмно-зелёном паспарту.

**Палитра** (взята из `Brand_style.jpg`):

| Роль | Цвет |
| --- | --- |
| Бумага | `#F8F4EA` |
| Шалфей (подложка секций) | `#E9EEE0` |
| Шалфей глубже (полоса цифр) | `#DDE5D1` |
| Чернила, глубокий зелёный | `#1E3628` |

**Индивидуальные акценты.** Страницы различаются между собой: у каждой свой
цвет кнопок, полосы цифр, подложки чередующихся блоков и бонус-блока. Общая
палитра и вёрстка при этом одни на все восемь.

Акцент-цвет волосяных деталей (номера разделов, буллеты, штрихи) тоже
переключается: охра, терракота `#A2551A` или золото `#846837`. Все связки
цветов проходят WCAG AA. Схемы заданы токенами `--ar-btn-*`, `--ar-band-*`,
`--ar-block-alt`, `--ar-bonus-*` в конце `src/landing.css`, переключение —
по атрибуту `data-ar-page` в корне страницы.

- `preview/` — полные страницы для просмотра в браузере (с фото и надписью «превью»).
- `tilda/` — сниппеты для вставки в блок **T123** в Tilda.
- `assets/img/` — 20 подготовленных фотографий для загрузки в Tilda.
- `src/` — исходники: тексты, стили, скрипт, сборщик.

Шапка, футер и логотип в страницы не входят — они уже есть на сайте.

## 1. Посмотреть превью

В `preview/` — восемь отдельных страниц, по одной на услугу, без общей сводной:

`preview/service-1.html`, `preview/service-2.html`, … `preview/service-8.html`.

Открывайте нужный файл напрямую. Страница со списком всех восьми не создаётся.

Если браузер капризничает с локальными файлами, запустите сервер из папки `landing`:

```
py -m http.server 8137
```

и откройте `http://127.0.0.1:8137/preview/service-1.html` (дальше — `service-2` … `service-8`).

## 2. Вставить страницу в Tilda

1. Откройте страницу услуги в Tilda.
2. **Добавить блок → Другое → HTML-код (T123).**
3. Откройте нужный файл из `tilda/`, скопируйте его целиком и вставьте в поле кода блока.
4. Сохраните и опубликуйте страницу.

Один сниппет — одна страница. Не вставляйте два сниппета на одну страницу: у них
общие имена стилей и скриптов.

Блок занимает всю ширину страницы, поэтому фоновые фотополосы и тёмные секции
работают от края до края.

---

## 3. Настроить попап

В самом начале сниппета есть блок настроек:

```html
window.AR_POPUP = "zayavka";
```

`zayavka` — это placeholder. Замените его на ID вашего попапа в Tilda.

**Где взять ID.** Откройте в Tilda блок попапа (Pop-up) → настройки блока → поле
«ID попапа». Например, если там `myform`, то в сниппете должно быть:

```html
window.AR_POPUP = "myform";
```

Все кнопки страницы получат ссылку `#popup:myform` и будут открывать этот попап.
Можно указать и целиком `"#popup:myform"` — скрипт поймёт.

**Если попап не найден** (ID не совпал или попап не добавлен на страницу), кнопка
не уводит в пустоту: страница плавно прокручивается к финальному блоку с призывом.
Всё равно лучше проверить ID после публикации.

## 4. Подключить фотографии

Файлы из `assets/img/` нужно загрузить в Tilda и вставить ссылки в настройки.

1. В Tilda: **Настройки сайта → Файлы** (или раздел «Файлы») → загрузите 20 файлов.
2. Скопируйте прямую ссылку на каждый файл (она начинается с `https://static.tildacdn.com/...`).
3. Впишите ссылки в блок настроек сниппета:

```html
window.AR_IMG = {
  band: "https://static.tildacdn.com/.../service-1-band.jpg",
  accent: "https://static.tildacdn.com/.../service-1-accent.jpg",
  final: "https://static.tildacdn.com/.../service-1-final.jpg"
};
```

- `band` — широкая фотополоса под первым экраном;
- `accent` — вертикальная врезка справа;
- `final` — кадр справа в финальном блоке (портрет 4:5).

Врезка есть только у услуг **1, 2, 3 и 5**. У услуг 4, 6, 7 и 8 оставьте только
`band` и `final`, строку `accent` можно удалить.

Пока ссылки пустые, на месте фото стоит тёмно-зелёная плашка — страницу можно
вставлять и смотреть, вёрстка не ломается.

| 05 · Организационный психоанализ и терапия бизнеса | `service-5-band.jpg`, `service-5-accent.jpg`, `service-5-final.jpg` |

**Про фотографии.** Фото не тонируются: в CSS только лёгкая десатурация

остаются натуральными и работают как «окна» в тёмно-зелёной полосе-паспарту.
Если захотите заменить фото, берите такие же спокойные горизонтальные кадры 16:9
без крупных лиц и кислотных цветов — они встанут в тот же ритм.

## 5. Цены и тексты

Цены и тексты уже стоят в готовом HTML. Их можно править прямо в Tilda: откройте
код блока, найдите раздел «Стоимость» и измените сумму. Пересборка для этого не
нужна.

Если правок много, удобнее менять исходники:

- `src/content.py` — все тексты, цены, состав блоков;
- `src/landing.css` — оформление;
- `src/landing.js` — поведение (попап, FAQ, появление блоков).

Пересборка:

```
cd consulting/landing
py src/build.py
```

Нужен Python 3.10+. Команда заново создаст `preview/` и `tilda/`.

> **Важно:** пересборка перезаписывает сниппеты, а вместе с ними — настройки
> `AR_POPUP` и `AR_IMG`. Если вы уже настроили попап и фото, перенесите эти
> значения в новые файлы (или правьте цены сразу в Tilda).

`py src/images.py` нужен только при замене исходных фотографий — он пересобирает
файлы в `assets/img/` (требуется Pillow).

## 6. Что уже учтено

- **Адаптив.** Проверено на 360, 768 и 1440 px: горизонтальной прокрутки нет.
  Таблица сравнения на телефоне прокручивается внутри своего блока, страница — нет.
- **Доступность.** Контраст текста не ниже AA, видимый фокус на кнопках и ссылках,
  FAQ размечен через `aria-expanded` / `aria-controls`, уважается
  `prefers-reduced-motion`.
- **Без библиотек.** Никаких jQuery, слайдеров и сборки. Только Google Fonts.
- **Шрифты.** Один шрифт на все страницы — **Roboto**, без исключений: буквы и
  цифры только им. Используются три начертания: Light 300 (крупные заголовки,
  суммы, цифры-факты), Regular 400 (текст), Medium 500 (надзаголовки, номера,
  кнопки). Подключается через `@import` в первой строке CSS; если нужен локальный
  шрифт, замените эту строку и `--ar-font` в переменных.
- **Изоляция стилей.** Все правила скоупятся в `.ar-landing`, списки и отступы
  защищены от базовых стилей Tilda. Сниппет проверен внутри реальной вёрстки Tilda.
- **Кнопки.** Три CTA на страницу: первый экран, блок цены, финал. Плюс текстовые
  ссылки «Стоимость и форматы».

Автор: **Vitaly Gariev**, [Pexels](https://www.pexels.com/). Лицензия Pexels
разрешает бесплатное использование без указания авторства, поэтому подписи

Имя автора и источник оставлены здесь, в README, для внутреннего учёта.

**Кадры в финальном блоке.** Справа в финале у каждой страницы своё фото —
вертикальный фрагмент 4:5. Фрагменты взяты из тех же 12 исходников, но:
(1) ни один не занят на самой странице (не повторяет полосу и врезку),
(2) обрезка другая, поэтому кадр не дублирует чужой. Подборка и сдвиги
обрезки — в `FINAL` внутри `src/images.py`.
